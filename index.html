Tipos Primitivos e Variáveis

Como o JavaScript guarda e manipula informações.

1 O que é um Tipo de Dado?

Um tipo de dado define que tipo de valor pode ser armazenado em uma variável. Pode-se pensar na variável como uma caixa com etiqueta: o tipo da etiqueta determina o que pode ser guardado dentro.

Em JavaScript, os tipos primitivos guardam um valor simples e direto.

2 Os 5 Tipos Primitivos

string Texto

Sequência de caracteres entre aspas duplas, simples ou crase.

jsconst nome = "Marcos"; const sobrenome = 'Silva'; const msg = `Olá, ${nome}`;

number Número

Inteiros e decimais. O JavaScript trata todos como number.

jsconst idade = 30; const preco = 3.14; const negativo = -10;

boolean Lógico

Representa apenas dois estados: verdadeiro ou falso. Essencial para decisões.

jsconst ativo = true; const logado = false; const maiorIdade = idade >= 18; // true ou false

undefined Não definido

Variável declarada, mas sem valor atribuído. É o JavaScript informando que nada foi definido ainda.

jslet valor; console.log(valor); // undefined

null Vazio intencional

Valor atribuído de forma proposital para indicar ausência de valor.

jsconst vazio = null; console.log(vazio); // null

Diferença prática: undefined vs null

undefinedO sistema informa: "nenhum valor foi definido". Ocorre quando a variável foi criada e ainda não recebeu nada.
nullA pessoa desenvolvedora informa: "defini como vazio". Ocorre quando há intenção explícita de indicar ausência.

3 Variáveis: var, let e const

Declaração é criar a variável. Atribuição é dar valor a ela. Inicialização é fazer os dois juntos.

js// declaração var username; // atribuição username = "Marcos"; // inicialização (forma mais usada) const age = 30;
PalavraPode alterar?EscopoUso atual
varSimFunção / GlobalEvitar — legado, vaza escopo
letSimBloco {}Usar quando o valor precisa mudar
constNãoBloco {}Padrão recomendado
💡 Recomendação: iniciar sempre com const. Se houver necessidade de alteração posterior, trocar para let.

4 Bloco {} e Interação com o usuário

Bloco {}

Agrupa instruções. Variáveis criadas com let e const dentro do bloco existem apenas ali dentro. Isso protege o código.

jsif (true) { const mensagem = "Dentro do bloco"; console.log(mensagem); // funciona } // console.log(mensagem); // erro

alert() e prompt()

alert() exibe mensagem. prompt() solicita dado e sempre retorna string.

jsalert("Olá, bem-vindo!"); const nome = prompt("Qual seu nome?"); const idadeTxt = prompt("Idade?"); const idade = Number(idadeTxt); alert(`Olá ${nome}, você tem ${idade} anos`);
⚠️ prompt() retorna string. Para cálculo, converter com Number().
